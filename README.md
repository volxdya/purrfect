# purrfect 🐾

Соцсеть красивых котиков в духе Pinterest: лента-масонри, реакции, битвы и стикеры в стиле Y2K.

## Запуск

Нужен Node.js 22 или новее.

```bash
npm install
```

```bash
npm run seed
```

```bash
npm run dev
```

Открой http://localhost:5173. Команда `seed` добавляет 24 нарисованных демо-котика, она нужна один раз. Войти в демо-аккаунты нельзя, так что заведи свой.

## Что умеет

- **Лента:** масонри, бесконечная прокрутка, сортировка «свежие / горячие / подписки», поиск, теги и трендовые теги.
- **Котики:** загрузка с редактором стикеров и подписями-мемами, паспорта котиков с кармой.
- **Общение:** 6 реакций (двойной клик по фото ставит 😻), комментарии, подписки, коллекции (в том числе приватные), уведомления.
- **Игры:** котомэтч со свайпами, битвы с рейтингом Elo, топ недели, зал славы.
- **Каждый день:** кот дня, кото-гороскоп, серия заходов.
- **Прогресс:** уровни и 10 ачивок, одна из них секретная.
- **Для настроения:** мурчание, конфетти из лапок, курсор-лапка, рандомный кот, тёмная тема и секретный код 🕹️.

## Команды

| Команда | Что делает |
| --- | --- |
| `npm run dev` | API на :3001 и Vite на :5173 |
| `npm test` | тесты API и безопасности |
| `npm run build` | сборка сервера и клиента |
| `npm start` | продакшен: всё на одном порту, :3001 |

## Продакшен

Запускай за HTTPS-прокси: в продакшене cookie помечены `Secure`. Переменные окружения: `API_PORT`, `HOST`, `DATA_DIR`. Чтобы попробовать сборку локально по http, задай `INSECURE_COOKIES=1`.
